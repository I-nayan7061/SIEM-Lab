What is a SIEM?

Security Information & Event Management: a centralized brain (like Splunk or Elasticsearch) that ingests millions of logs to find cyber attacks.

What is Detection-as-Code?

Writing detection rules just like software code: using Git, code review, and automated unit tests to guarantee 0 false positives before deploying.

What is Sysmon?

Microsoft System Monitor: a specialized Windows kernel sensor that monitors process spawns, memory access, and unauthorized changes.

What is Sigma?

The universal open-source standard for detection rules. Write a rule once in Sigma YAML, and it automatically converts to Splunk SPL or Elastic KQL.
